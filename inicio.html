Intervalo de registro

La frecuencia predeterminada es de 5 minutos. El navegador debe permitir el GPS.

Precisión mínima aceptable

Define el margen de error máximo del GPS. Si la precisión del dispositivo es peor que este valor, el punto no se guarda. Un número menor exige mayor precisión.

Presentación

Importar CSV desde una URL

Usa solo un enlace de exportación CSV compartido por ti. No permite acceder a hojas privadas sin autorización ni requiere publicar tu hoja.

Direcciones postales (opcional)

Sin fichas. Puedes escribir la dirección completa de cada punto o buscar una dirección aproximada con una clave propia de Geoapify, solicitada únicamente cuando pulses «Buscar dirección». Las coordenadas se envían al proveedor solo si lo autorizas.

La clave se conserva solo en este navegador, no se exporta ni se incorpora a los mensajes compartidos. En aplicaciones web la clave es visible y debes restringirla por origen o referente en Geoapify.

Geoapify devuelve direcciones aproximadas cuando existen; pueden faltar calles o números. Para una dirección exacta, introdúcela manualmente.

Eliminar información local

Borra los registros y favoritos de este navegador. No modifica datos remotos ni permite recuperarlos sin una copia.

Privacidad: la geolocalización se guarda localmente en este dispositivo. Esta versión no envía automáticamente coordenadas a Google Sheets. El rastreo periódico en segundo plano no está garantizado si el navegador suspende la pestaña o la aplicación.
